# Login Feature

## User Story

As a customer,
I want to log into the application,
so that I can access the product inventory.

## Acceptance Criteria

1. A user with valid credentials can log in successfully.
2. A user with an invalid password cannot log in.
3. A locked-out user cannot log in.
4. Username is mandatory.
5. Password is mandatory.
